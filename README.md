# Pharmacy Guide 💊

A modern, responsive web guide that allows users to browse different drug classifications, view sub-categories, and learn about active ingredients.

## Project Overview
This project is designed to help users explore medication classifications easily. It features a clean user interface with a modern blue hero section, displaying key statistics and a grid of interactive cards for each drug category. 

## How it was built
- Built from scratch using **HTML5** and **CSS3**.
- Used **Font Awesome** for clean and scalable icons (like the heart and arrows).
- Focused on semantic HTML and responsive design to ensure it looks good on both mobile and desktop screens.
- Used custom CSS for styling, hover effects, and layout management.

## How to Run / Use
1. Clone this repository to your local machine or download the ZIP file.
2. Open the project folder.
3. Double-click on the `index.html` file to open it in your browser.
4. *(Alternative)* If you are using VS Code, right-click on `index.html` and select **"Open with Live Server"**.

## Features
- **Interactive Cards:** Each card includes a numbered badge, title, and description.
- **Hover Effects:** The cards and icons respond beautifully when hovered over.
- **Favorites:** A functional "Favorite" (heart) button icon on each card.
- **Navigation:** Arrow icons indicate clickable links to sub-categories.
